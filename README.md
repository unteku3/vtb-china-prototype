# ВТБ Онлайн · Китай — учебный прототип

Неофициальный кликабельный прототип раздела «Китай» внутри ВТБ Онлайн. Он показывает покупку юаней, QR-оплату, возвраты, крупный перевод и привычные банковские экраны. Все суммы, реквизиты и результаты операций — демонстрационные. Прототип не подключён к банку и не выполняет настоящих платежей.

[Открыть прототип на GitHub Pages](https://unteku3.github.io/vtb-china-prototype/)

## Запуск

Откройте `index.html` в браузере — сборка и установка зависимостей не нужны. Также можно запустить `python3 -m http.server 8000` в корне репозитория и открыть `http://localhost:8000`.

На компьютере список экранов находится слева, переключатели сценариев — справа. На узком экране используйте «Экран» и «Сценарии» над телефоном. «Схема переходов» открывает карту маршрутов. «Начать демонстрацию заново» сбрасывает состояния.

## Данные и файлы

Интерактивные сценарии выполняются локально в браузере. Выбранные файлы не отправляются на сервер; чеки и документы создаются на устройстве и помечены как учебные. В `localStorage` сохраняются только состояния знакомства и подсказок. Для работы прототипа внешние API не требуются.

## Визуальные ориентиры и шрифт

Дизайн опирается на публичные материалы ВТБ Онлайн. Точное соответствие внутреннему UI kit банка не заявляется; прототип не является официальным приложением ВТБ.

Встроен PT Root UI от Paratype по **SIL Open Font License 1.1** — лицензированная замена Omega UI. Текст лицензии: [`fonts/OFL.txt`](fonts/OFL.txt). Источник файлов и контрольные суммы: [`fonts/PROVENANCE.json`](fonts/PROVENANCE.json). Лицензия шрифта не распространяется автоматически на остальной проект.

## Публикация

GitHub Pages публикует корень ветки `main`. После отправки изменений сайт обновляется автоматически; `.nojekyll` отключает обработку Jekyll. Все стили, скрипты и шрифты находятся в репозитории.
